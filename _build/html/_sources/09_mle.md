# Distribution Learning with Maximum Likelihood Estimation

1. (MLE) COVID in a town is modelled using Bernoulli distribution. The probability of a person having COVID is modelled as a Bernoulli random variable (1=positive, 0=negative) $$p(x;\mu)=\mu^x(1-\mu)^{1-x}$$
      - Given the data of COVID status of the population, estimate the value of $\mu$.
      - Using this model, tell what is the expectation the a given person in the town is COVID positive.

2. (MLE) Samples of flowers are given as $\{\mathbf{x}_n^{\intercal}\}=\{[2,4],[3,4],[4.5,3.5],[4,4.5]\}$. If $p(\mathbf x)$ is modeled as a Gaussian distribution, find ML estimates of its parameters.

3. (MLE) If $x\sim \mathcal{N}(\mu,\sigma^2)$, with $\mu=5, \sigma=2$, estimate
      - $\mathbb{E}[(x-2)^2]$
      - $\mathbb{E}[\sin(x-5)]$
