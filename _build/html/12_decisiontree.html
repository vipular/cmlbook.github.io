Decision Trees#

(1. TREE) A decision tree can be implemented in a code using if-else conditions. To classify a flower into R, L or J, using two features height h and diameter d, the following decision tree is made:

if h>2:
   y=L
elif d<1.5:
   if h>1.2:
      y=J
   elif d<1:
      y=J
   else:
      y=R
else:
   y=R

  • Draw the regions in the input space corresponding to the three classes

  • Draw the decision tree (with nodes)
